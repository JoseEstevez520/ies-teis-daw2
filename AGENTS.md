# AGENTS.md

Repo colaborativo de apuntes y recursos de 2º DAW (IES de Teis, curso 2026-2027). Lo
edita toda la clase, no una sola persona.

## Dónde mirar

| Si... | Lee |
|---|---|
| vas a escribir o revisar un apunte, README o cualquier `.md` de este repo | [.agents/skills/apuntes-claros/SKILL.md](.agents/skills/apuntes-claros/SKILL.md) |
| vas a crear o mejorar cómo se ve algo en la web del repo (diagramas, piezas interactivas) | [.agents/skills/apuntes-web/SKILL.md](.agents/skills/apuntes-web/SKILL.md) |
| vas a aportar contenido por primera vez | [CONTRIBUTING.md](CONTRIBUTING.md) |
| necesitas el horario de clase | [horario/](horario/) |

Módulos: `modulos/{DAW,dwcs,diw,dwcc,despregamento,dasp}`.
Contenido extra (no es temario): `extra/{ia,diseno-web,ideas-proyecto-fin-curso,herramientas,open-source}`.

## Reglas

- No es para entregas ni trabajo evaluable individual. Eso va en el repo de cada uno.
- Push directo, sin pull requests (ver [CONTRIBUTING.md](CONTRIBUTING.md)).
- En la [web del repo](extra/herramientas/web-del-repo/) cada página es un componente
  compuesto a mano, y el `.md` es su versión de GitHub. Si cambias un `.md`, cambia también
  su página en el mismo cambio; si creas uno nuevo, créale su página y regístrala en
  `src/data/paginas.js` (cómo, en el
  [AGENTS.md de la web](extra/herramientas/web-del-repo/AGENTS.md#cada-página-un-componente)).
  Si no sabes Vue, cambia el `.md` y avisa.
