# Diseño web

Herramientas externas para paletas de color, tipografías y referencias de UI.

## Herramientas

- [uicolors.app](https://uicolors.app/generate) — genera una escala de color completa
  (50–950) de Tailwind a partir de un color base.
- [tweakcn](https://tweakcn.com/editor/theme) — editor visual de temas: saca variables
  CSS/Tailwind, no componentes.
- [WhatTheFont](https://www.myfonts.com/es/pages/whatthefont) — identifica una tipografía
  a partir de una imagen.
- [Mobbin](https://mobbin.com/) — capturas reales de UI de apps y webs, para referencia.
- [ASCII Magic](https://www.ascii-magic.com/) — convierte imágenes/vídeos a ASCII art.
- [Design Minis](https://www.designminis.com/) — colección curada de herramientas de
  diseño pequeñas.
- [Refero Styles](https://styles.refero.design/) — más de 2000 sistemas de diseño reales
  (colores, tipografía, espaciado) sacados de webs de producto.
- [Shader Gradient](https://shadergradient.co/) — generador de fondos con degradado o
  shader, exporta a CSS.
- [Dropdown menu morph](https://transitions.dev/detail.html?t=dropdown-menu-morph) —
  patrones de transición CSS/JS explicados paso a paso.
- [Motion Prompts](https://motionprompts.dev/) — animaciones con GSAP listas para copiar.
