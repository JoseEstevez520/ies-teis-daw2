# Fuentes

La tipografía decide más de lo que parece: con la misma maqueta, una fuente la hace seria y
otra la arruina. La regla de partida es una sola familia, o dos como mucho.

## Cómo elegir

- Una fuente para todo suele bastar. Si usas dos, que se diferencien (una de texto y una de
  titulares), no dos parecidas.
- Mira las letras que la delatan: la `a`, la `g`, la `R` y los números.
- Prueba con el texto real de tu web, no con "Lorem ipsum".
- El contraste lo dan el tamaño y el peso, no mezclar fuentes.

## Las de siempre

Inter, Roboto, Arial o las del sistema salen en casi todo lo que hace la IA, y no son malas:
son neutras y se leen bien. El problema es que, al usarlas todos, todo se parece. Si quieres
que lo tuyo destaque, busca una con carácter (una serif, una grotesca con personalidad, una
mono) y resérvala para los títulos.

## Recursos

- [Google Fonts](https://fonts.google.com/) — miles de fuentes libres, con la licencia
  incluida. El punto de partida.
- [Fontshare](https://www.fontshare.com/) — fuentes de calidad, gratis también para uso
  comercial.
- [WhatTheFont](https://www.myfonts.com/es/pages/whatthefont) — identifica una tipografía a
  partir de una imagen.
- [Typescale](https://typescale.com/) — calcula la escala de tamaños: la proporción entre
  título, texto y pie.
