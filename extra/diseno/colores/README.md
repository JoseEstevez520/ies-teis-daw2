# Colores

El color en una web no es decorar: marca jerarquía y significado. Casi todo se resuelve con
grises y un solo color de acento.

## Reglas de partida

- Grises para el texto, el fondo y los bordes; un color de acento para lo que importa.
- Menos colores, mejor. Si todo es de color, nada destaca.
- El texto y su fondo necesitan contraste suficiente (4.5:1 en el texto normal).

## Recursos

- [uicolors.app](https://uicolors.app/generate) — genera una escala de color completa
  (50–950) de Tailwind a partir de un color base.
- [tweakcn](https://tweakcn.com/editor/theme) — editor visual de temas; saca variables CSS y
  de Tailwind, no componentes.
- [Refero Styles](https://styles.refero.design/) — más de 2000 sistemas de diseño reales
  (colores, tipografía, espaciado) sacados de webs de producto.
- [Shader Gradient](https://shadergradient.co/) — generador de fondos con degradado o shader;
  exporta a CSS.
- [Contrast Checker](https://webaim.org/resources/contrastchecker/) — comprueba si un texto se
  lee sobre su fondo.
