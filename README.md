# ies-teis-daw2

Este repo es un espacio colaborativo para que a toda la clase de 2º DAW le vaya mejor:
apuntes, conocimientos extra, ideas y herramientas que cualquiera puede usar.

## Empezar

Lo mejor es verlo en la web: **<https://joseestevez520.github.io/ies-teis-daw2/>**. Está todo el
contenido, navegable y visual.

O arrancarla en tu equipo:

```bash
git clone https://github.com/JoseEstevez520/ies-teis-daw2.git  # traer el repo
cd ies-teis-daw2/extra/herramientas/web-del-repo               # la web del repo
npm install                                                    # instalar las dependencias
npm run dev                                                    # arrancarla
```

Abre `http://localhost:5173`. Necesita Node 20 o superior. Los apuntes también se leen en
GitHub.
