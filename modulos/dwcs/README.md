- [Servicios e inyección](servicios-e-inyeccion.md): la lógica del negocio en un servicio y
  cómo se inyecta.
- [Optional](optional.md): un envoltorio para los valores que pueden no estar.
- [Enum](enum.md): un tipo con un conjunto cerrado de valores.
- [Scopes y estado](scopes-y-estado.md): cuántas instancias crea Spring de cada bean (singleton,
  prototype, sesión HTTP).
